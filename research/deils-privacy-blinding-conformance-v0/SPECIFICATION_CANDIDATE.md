# Research candidate boundary v0

The caller selects `research.deils-privacy-blinding.v0` independently of content; an untrusted content member cannot downgrade that policy. The `research.deils-legacy-integer-replay.v0` lane is an explicit laboratory replay of historical unblinded behavior, not a reassignment of a historical profile identity. Unknown versions refuse before hashing.

The existing formula is unchanged: `content_commitment = "sha256:" + lowercase_hex(SHA256(JCS(content)))`. Entire admitted content is committed, including blinding. No ReceiptOS canonicalizer, receipt_root, action-subject identity, profile tag or domain prefix is inserted into this preimage. Root identity labels are distinct; this research does not imply that identically encoded values acquire cryptographic domain separation automatically.

## Admission and JCS

The experiment admits JSON objects/arrays/strings/booleans/null and integer tokens in [-9007199254740991,9007199254740991], with scalar Unicode strings and unique object members. Fraction/exponent tokens are deliberately outside this bounded research domain. This is narrower than RFC8785 and some historical examples; it is not a new assertion that DEILS or JCS forbids fractions. Negative-zero integer tokens canonicalize to 0. Arrays preserve order; keys sort by UTF-16 code units; strings preserve Unicode without normalization and use ECMAScript escaping. JCS receives the parsed value, not served wire bytes. Reordered members, whitespace and equivalent escapes remain allowed. Surrogates, duplicate keys, unsafe integers and malformed JSON are refused before hashing.

Python uses rfc8785 0.1.4. Node independently parses the bounded input without losing duplicate/unsafe tokens and serializes primitives with ECMAScript JSON.stringify and recursively sorted UTF-16 keys. Exact canonical UTF-8 hex and recomputed digest are asserted, not only verdict markers. A supplementary-plane key fixture distinguishes UTF-16 from Python code-point sorting. This is not a general-purpose verification engine or universal JCS certification.

## Blinding and reveal

For this caller-selected privacy candidate, root content must be an object. A missing `blinding` stops with status UNVERIFIABLE, state null, reason `RESEARCH_REQUIRED_BLINDING_ABSENT`. That reason is local research bookkeeping, explicitly NOT a normative DEILS error name. No hash is evaluated. The normative spelling remains an open source-publication question.

Present blinding must be a string of exactly 64 lowercase hex characters (32 bytes). Refusal reason is `blinding_malformed`, validation stage, no canonical bytes/digest. This spelling and requirement are user-reported collaborator agreement, not present in the inspected pinned extension source. Valid-format wrong blinding is hashed normally and yields the existing terminal state `content_commitment_mismatch`. Matching reveals yield `content_bound`. Undisclosed content remains `content_withheld`, no hashing. A malformed commitment reference is a format refusal, not content mismatch.

Operational issuer requirement: a fresh 32-byte CSPRNG draw per commitment, generated by the platform cryptographic random source. This corpus intentionally uses fixed public test nonces for replay. Local format checking cannot establish entropy, secrecy, independent generation, or global reuse absence. A reuse case deliberately binds successfully and is NOT advertised as privacy certification.

## Outcomes and grading

The native reveal states remain separate from research status projection: content_bound -> VERIFIED for binding only; content_commitment_mismatch -> REFUTED; absent/admission evidence -> UNVERIFIABLE. Neither is a legal finding or execution permission. Every result includes stage, hash_evaluated, canonical_utf8_hex and recomputed_commitment. Malformed data never fabricates a digest.

Both adapters are REPORTER: they do not read expected values. Canonical runner grades every returned result. Missing/extra/malformed reports and ungradable expected declarations follow existing REPORT_CONTRACT/exit2; mismatched established relations are SUITE/exit1; runtime preconditions are RUNNER; source/vector drift is DRIFT. Empty corpora cannot certify a case. No global runner reclassification is introduced.
